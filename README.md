# 🔐 Microsoft Entra ID – IAM Lab

## Create and Manage Microsoft Entra ID Users in the Portal

### Lab Objectives
1. **Create Microsoft Entra ID User Accounts**
2. **Modify a Microsoft Entra ID User Account**
3. **Revoke Access to a Microsoft Entra ID User Account**
4. **Delete a Microsoft Entra ID User Account**


## Create Microsoft Entra ID User Accounts 👤
1. Log in my Entra ID tenant. 
2. Under **Users** tab I selected **All Users**
3. Selected  **+ New User**
